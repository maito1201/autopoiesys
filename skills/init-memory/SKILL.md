# init-memory — 覚え書きの場所を作る

1. `${CLAUDE_PLUGIN_ROOT}/template/MEMORY.md` を写して入口を作る。本人に目標を聞き、本人の言葉のまま「今の目標」に書く。
2. この場所の過去のやり取りと自動記憶（`~/.claude/projects/` の、この場所に当たるフォルダと、その中の `memory/`）があれば、最初に全部読む。本人が既に決めた目的と、既に退けた案がそこにある。次に、リポジトリなど既にある資料から、この目標に要る事を拾って notes/ に書く。1つの主題に1枚。確かめた事には、どう確かめたかを添える。確かめていない事は、確かめていないと書く。
3. 対象の CLAUDE.md に1行足す: `覚え書き: <path>/MEMORY.md — 仕事の始めに読む。分かった事は notes/ に書く`
4. 入口は小さく保つ。細かい事は notes/ に置き、入口からは場所だけを指す。毎回読み込む文が長いほど守られにくくなるため。

覚え書きの使い方（いつ何を読むか、何を記録するか）は決めない。何のための場所かだけを伝え、判断は任せる。
