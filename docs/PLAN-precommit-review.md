# 事前固定: コミット前総点検の判定基準

証拠を並べる前に固定する。

## 判定基準

1. **「知性と呼べるか」はT009で事前固定した5主張（C1〜C5）の枠組みをそのまま使う。**
   基準を作り直さない（結果を見た後の基準変更を避ける）。判定を動かしてよいのは
   **T009以降に増えた機械記録**だけであり、会話の印象・自己評価は使わない
2. **乖離の整理は「器官の有無」と「挙動の実証」を分けて書く。**
   器官が存在することを機能の実証と書かない（T009監査の規律を継承）
3. **キリの良さの判定は決定的ゲートのみ**: tests / regression（golden・failure_lint）/
   validate / check / unbound / 未蒸留タスク / skills sync。主観の「切りが良い気がする」を
   判定に使わない。開いたままの項目（F006等）は隠さず「開いている」と書く
4. 反証・未実証を先に書く
