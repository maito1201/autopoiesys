# 反証の記録

成果物を出すたびに1行。「この判断が外れていたら、何がいつ観測されるか」。観測されたら行を消さず、末尾に「→ 観測 YYYY-MM-DD: 何が起きたか」を足す。
セッション冒頭に未観測の行を読む。判定は人間。このファイルが読まれなくなる長さになったら、それ自体が官僚化の観測である。

## YYYY-MM-DD 思考回路を作った

- 広く集めた topics は読まれる → 10タスク後に一度も読まれていないファイルが半数を超えたら外れ。確認: セッションログの Read 対象
- 回路はスキル無しで効く → 本人が /run-task を呼ばない依頼で瞬間0（アウトカム確定）が起きなければ外れ。確認: 依頼直後の最初の応答
