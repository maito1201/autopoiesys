# dream — 覚え書きを確かめ直す

誤った覚え書きは、次の回にそのまま信じて使われる。仕事の最中には気づけないので、区切りで確かめ直す。

1. 元のやり取りから、本人の訂正と、自分の見立てが外れた場面を拾う（`python "${CLAUDE_PLUGIN_ROOT}/scripts/corrections.py" <記録のディレクトリ>` が本人の短い発話を日付つきで出す）。
2. notes/ の各記述を、元のやり取りと今のリポジトリに照らす。食い違う記述は直す。もう成り立たない記述と、理由の無くなった注意書きは消す。
3. 同じ事を書いた紙はまとめる。リンク切れを直す。
4. 入口（MEMORY.md）を今の目標と今の計画に合わせて書き直し、細かい事は notes/ へ下ろす。
5. よく変わる事（進行中の状態、数字）を優先して見る。全部を毎回確かめ直す必要はない。

直した記述には、何に照らして直したかを添える。
